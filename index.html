Calendar Import

An iPhone Shortcut reads today's calendar and sends the events here to review on the Log tab. Nothing is logged until you confirm it.

How to set up the Shortcut
  1. Open the Shortcuts app → ＋ → name it “Spoon Tracker Calendar”.
  2. Add Find Calendar Events. Set the filter to Start Date is today, sort by Start Date, oldest first.
  3. Add Repeat with Each (it uses the events). Inside it, add a Text action containing:
    Title|Start Date|End Date|Calendar
    Replace each word with the Repeat Item variable's matching detail. For Start Date and End Date, tap the variable and set Date Format to ISO 8601. Keep the | between them.
  4. After End Repeat, add Combine Text (Repeat Results, with New Lines).
  5. Add URL Encode on the combined text.
  6. Add Text: followed by the URL Encoded Text variable.
  7. Add Open URLs. It opens in your default browser, so use the same browser you track in (your data lives there).
  8. Optional: Automation tab → Time of Day (e.g. 7 PM daily) → Run Immediately → run this Shortcut.
